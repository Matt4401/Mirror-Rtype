---
description: Create a commit with a conventional message
---
1. Look at `git status` and `git diff` (staged changes, otherwise all).
2. Write a message in the format `type(scope): summary` (feat, fix, refactor, docs, test, chore),
   summary in the imperative, under 72 characters, with a body if the "why" is not obvious.
3. Show the message, then create the commit. Never push unless explicitly asked.
