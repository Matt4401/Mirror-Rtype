# Squacaron

Squacaron is a C++23 game engine written from scratch for the EPITECH Advanced C++ project. Two games run on it:

- **R-Type**, a networked multiplayer shoot'em up with an authoritative server ([gameplay](gameplay/levels.md)).
- **RLSS**, a 2D car football game, built to check that the engine does not depend on R-Type ([RLSS](rlss/index.md)).

## Core Architecture

Three parts:

- The server is authoritative: it runs the game logic, physics, collisions and enemies, and checks every player
  input.
- The client draws the game, reads the player's input and predicts the local ship until the server
  answers.
- The engine is an ECS with plugins. Plugins declare their dependencies and are started in dependency order
  (`engine::IPlugin`, `engine::PluginGraph`); they share services through `engine::Mediator`. Nothing in it is
  specific to R-Type (Track #1).

The menu leads to the architecture pages, the network protocol, the comparative studies and the API reference generated by Doxygen.
